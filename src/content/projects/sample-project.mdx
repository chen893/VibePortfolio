## 项目概述

这是我用来承载个人品牌与项目作品的作品集网站本体。它支持用 MDX 维护项目详情页面，并在首页/列表页以一致的视觉语言展示项目卡片与筛选交互，包括：

- 项目卡片与详情页（MDX 内容）
- 分类与技术栈筛选
- 响应式布局与移动端导航
- SEO 元信息与结构化数据（Person Schema）

## 技术亮点

### 前端技术
- Astro + React 混合渲染：静态优先，交互组件按需加载
- TypeScript：统一数据结构与组件 Props，降低维护成本
- Tailwind CSS：快速构建一致的赛博朋克风 UI 体系
- Framer Motion：为关键交互与转场提供细腻动效

### 内容与数据
- 项目内容采用 MDX，支持图文与结构化字段（标题、描述、技术栈、图片等）
- 个人信息与技术栈数据 JSON 化，便于后续扩展与替换

## 项目成果

- 面向中文用户的站内文案与导航体验
- 项目展示链路清晰：列表 → 筛选 → 详情 → 返回
- 视觉风格统一：字体、颜色、霓虹强调与终端风装饰保持一致

## 学习收获

通过这个项目，我把「视觉表达」与「工程化落地」结合起来：在保持风格化设计的同时，尽量让组件结构、内容维护与页面性能都更易扩展、可持续。
